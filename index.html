ProPublica to Sankey

A record of every way I tried to pull the Smithsonian's finances into a webpage. Four doors were locked, two were open, and the difference was never my code: it was whether the server sends the header that lets a browser read the reply. ProPublica doesn't; Wikidata does. Each folder below runs on its own.

The experiment

01 · Direct fetchCORS blocked
Call ProPublica straight from the page. No status, the browser kills it first.
02 · corsproxy.io (key)401 Unauthorized
Route through a proxy with an API key. We reached it; it refused the key.
03 · allorigins522 timeout
A keyless proxy. Works sometimes, times out often. Too flaky to build on.
04 · JSONP403 Forbidden
Load the response as a <script> to dodge CORS. Reached the server; it said no.
05 · Saved file + d3 tableWorks
Fetch a cached local file (downloaded once via a browser tab). Draws 13 years.
06 · Wikidata SPARQL + editsWorks live
A live SPARQL query for a VIAF id, plus the record's edit history. Keyless, no proxy.
